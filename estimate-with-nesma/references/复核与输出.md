# 复核与输出

## 临时输入

向生成器提供 UTF-8 JSON，顶层字段为：`subject`、`method` (`overview|detailed`)、`count_type` (`application|new|enhancement`)、`user`、`scope`、`boundary`、`evidence`、`data_functions`、`transactions`、`non_counted`、`assumptions`；增强应用净变化另传 `baseline_ufp`。

证据项使用 `id, role, source, version, location, fact, claims, traceable`，派生材料标 `derived`，冲突写 `conflict`。功能项使用 `id, name, type, change, evidence_ids`；详细数据项加 `ret, det`，详细事务项加 `det, ftr, processing`，删除/修改项按需加 `before_fp`。临时 JSON 不进入审阅包。

## 产物

只交付 `估算审阅报告.md`、`规范化功能清单.md`、`功能点计数证据.xlsx`。工作簿是结构化计数模型权威；Markdown 是可读投影。工作簿固定包含：`计数说明`、`证据登记`、`数据功能`、`事务功能`、`假设与冲突`、`汇总`、`复核记录`。

审阅者只编辑黄色解锁字段；公式和计数事实受保护。区分规则/公式检查、输入事实复核、NESMA/FPA 方法复核。任何修改都创建新版本目录并从证据及明确接受的反馈重跑；Schema 或 Generator 版本不同则严格不兼容，不迁移旧包。

阻断包仍生成三件套，但不显示正式总数，未决行不进入公式。首版状态只能是 `计数阻断` 或 `待复核`。
