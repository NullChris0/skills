# 计数判别访谈

在证据审查之后、写入计数模型之前完成本访谈。只处理证据仍有一种以上合法读法的分叉。交接、重启文本和上次已确认判别都不是证据，只能作为本轮草案。

NESMA 已定死的项按 [通用计数规则.md](通用计数规则.md)、[详细FPA-数据功能.md](详细FPA-数据功能.md) 和 [详细FPA-事务功能.md](详细FPA-事务功能.md) 执行，不问。复杂度档位由 DET×FTR 矩阵得出，用户不能改档。

## 必问类

证据已唯一决定的跳过。按以下顺序，每轮只问一个决定：

1. 逻辑文件拆合：一个候选数据组是独立 ILF/ELF，还是已有文件的 RET。
2. 基本过程同一性：一对或一组可能合并的用户动作是一个基本过程还是多个。
3. 该事务读/维护哪些已确认逻辑文件。拆合定完后能推导的跳过，只问仍分叉的事务。概要 FPA 不问本项。
4. 跨边界有哪些用户可识别 DET（有没有，不是叫什么）。一次一个过程。概要 FPA 不问本项。
5. 该过程是否含计算、派生、维护 ILF 或改变行为，以定 EO 或 EQ。

不把某个应用的具体文件或事务写成独立规则。详表命名不在本访谈决定，见详细 FPA 两份规则。

## 问法

只陈述分叉和已定位证据事实，不选边，不将草案称为推荐。「你来判断」不构成确认。

用户对当前决定表示「不知道」「解释一下」或同等意思时，说明各选项、现有证据、NESMA 检验和后果，不直接或附条件地建议某个选项，然后回到同一个待决定项。

用户无法回答时，该项保持未决，继续问其余分叉；全部问完后生成未完成的三件套审阅包。

## 冲突

答复与已定位证据冲突，且会改变已确认的计数对象、范围、应用边界、计数类型或方法时，本次启动确认失效：不生成审阅包，不恢复计数。其余冲突写入冲突并计数阻断，相关行不进入公式。

## 判别确认

全部必问分叉处理完后，在单独一轮显示一份只含本轮判别答复的摘要，到此停止。若无分叉，摘要写明无待确认分叉，仍须确认。即使证据审查已完整或要求直接填表，也等待下一条用户消息。只有对最新摘要的无条件肯定答复才写入计数模型。

修正、条件、歧义、参数变更或新发现的分叉使上次判别确认失效；从该分叉所属步骤接着问，再出一版完整摘要。

已确认判别只在当前 session 有效，写入审阅包「假设与冲突」，不写入 Skill、被估应用领域文档或作为确定知识。新 session 重新访谈。重启 prompt 可带上次已确认判别作草案，仍须再问并再次确认。
