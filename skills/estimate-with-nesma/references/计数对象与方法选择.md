# 计数对象与方法选择

明确计数是现有应用存量、目标应用存量、新建项目还是增强项目。应用边界是应用与用户的概念接口；计数范围是本次纳入的功能集合，二者不可互换。

- 新项目：目标系统本次范围内全部用户可识别功能按 ADD 计数，旧系统不作为计数对象。
- 存量应用：计数目标应用当前版本的全部用户可识别功能。
- 增强项目：只纳入新增、修改和删除的功能；当前四表契约尚未纳入增强项目的变更前/变更后字段，遇到增强项目先扩展契约，不静默套用新项目。

- 概要 FPA：已识别用户可识别逻辑数据、维护责任、基本过程及 ILF/ELF/EI/EO/EQ 类型。
- 详细 FPA：在概要门槛上，每个数据功能另有 RET/DET 详表及证据，每个事务功能另有带侧 DET/FTR 详表及证据。

本 Skill 不支持预估 FPA。详细资料不足时，可在用户未限定详细方法且概要门槛满足时采用概要 FPA；用户明确详细-only 时保持阻断。
