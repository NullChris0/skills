# 通用计数规则

从用户视角识别功能，不按页面、菜单、API、代码函数、数据库表、文件格式或记录行数计数。

- ILF：应用维护的用户可识别、逻辑相关持久数据或控制信息。
- ELF：另一应用维护、本应用持续引用的同类数据；一次性交换文件不是 ELF。
- EI：信息进入边界，主要维护 ILF 或改变系统行为。
- EO：主要向外呈现信息，且包含计算、派生、ILF 维护或行为改变。
- EQ：主要检索并直接呈现已有信息，不含 EO 特有处理。

事务以用户可识别、完整、使应用达到一致状态的最小基本过程计数。触发方式、页面数量、记录数量、筛选值组合、输出介质、排序或简单拼接不复制功能。自动触发的明确用户功能仍可计数；纯技术动作不计。

单独保留非功能需求、质量约束、技术任务及其他排除项，并写明理由。假设和冲突不静默变成事实。证据仍分叉的逻辑文件拆合、基本过程同一性、事务引用的逻辑文件、跨边界 DET 有无、以及 EO/EQ 不得静默选边，按 [计数判别访谈.md](计数判别访谈.md) 处理。
