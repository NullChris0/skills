# 成稿启动

阶段二只需确认输入和输出，不重新访谈 NESMA 判断。

## 一次确认

从当前 prompt、交接材料和仓库事实能确定的直接填好，剩余内容一次询问：

1. 阶段一 `计数模型.json` 路径；如有 `功能点计数证据.xlsx`，同时给出路径。
2. 后端、前端及其他证据仓库路径，以及固定 commit/tag/分支。分支和 tag 必须解析为 commit，不默认使用当前工作区。
3. 项目领域文档、规格、数据字典、合同范围或接口材料路径；没有就写“无”。旧交付件和旧接口表目录只可作版式参照，不作为事实来源。
4. 本 session 是否授权现网、数据库、浏览器或远程接口的只读访问。
5. 新输出目录；目录必须不存在或为空。
6. 封面需求名和封面月份。需求名由用户指定，只写名称本身，不含“需求说明书”后缀；月份使用 `YYYY年M月`。不得从域名自动拼接封面名称。
7. 功能清单模板路径；默认使用本 Skill 的 `assets/联通功能清单模板.xlsx`。Word 由生成器从交付模型写出。
8. 数据割接、迁移、环境切换、线下操作等非计数支撑工作的材料入口；没有就写“无”。

确认后固定证据基线。发现计数模型与代码事实冲突时返回阶段一，不在成稿阶段改数。
