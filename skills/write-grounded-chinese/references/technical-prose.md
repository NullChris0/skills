# 技术文章

用于个人技术笔记与技术博客。

- 对版本、标准、产品行为和其他可变事实主动查找官方文档、一手资料或实际系统证据。必要时用可靠二手来源补背景，不用它替代可获得的一手来源。
- 区分观察、引用、推断和个人判断。推断写明依据并把结论强度限制在材料范围内。
- 材料仍不足时缩小论题或降低结论强度。用户要求完整覆盖而现有材料无法支撑时，先集中追问，不用抽象推演填满篇幅。
- 外部事实提供必要链接或引用；个人经历不伪造公开来源，内部材料不泄露出处。
- 允许解释复杂技术的类比，但明确对应关系与失效边界。类比不证明机制真实存在。
- 结尾收束已经论证的结论、限制或下一步，不突然扩张到时代、文明或所有人。
