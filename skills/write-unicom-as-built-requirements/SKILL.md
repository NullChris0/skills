# 联通竣工态需求说明书

一次调用只处理一个重写系统。待完善稿供用户润色补充后提交客户确认和验收，并完整呈现可计量的已交付工作；实际竣工行为是事实基线，NESMA 结论是计量基线。

## Workflow

1. 读取并完成 [启动访谈.md](references/启动访谈.md)。在用户于后续一轮明确确认完整摘要前停止，不访问业务证据、不创建文件。
2. 确认后读取并完成 [证据审查与阻断.md](references/证据审查与阻断.md)。审查完成前不得读取成稿指令、填充模板或生成交付件。
3. 任一实质冲突均阻断成稿。完成本轮只读审查，一次列明全部已发现冲突、证据、影响和所需修正，然后停止。
4. 只有证据审查无阻断项时，读取并执行 [成稿与校验.md](references/成稿与校验.md)。

使用 `assets/联通项目需求说明书模板.docx` 和 `assets/联通功能清单模板.xlsx` 生成待完善稿。已安装且允许语义触发的 Word、Excel Skill 优先；没有时使用现有本地文档能力。中文成稿使用已安装的 `write-grounded-chinese` Skill 约束事实、决策和未知的身份。

不承担 NESMA 识别、计数或复核，只接受已复核的详细 FPA 结论。缺少正式结论或使用其他方法时阻断，并提示用户另行完成 NESMA 详细估算。
