# 联通竣工态需求说明书

一次调用只处理一个重写系统。完整呈现已交付能力及其工作内容，帮助开发者按联通规范提交需求规格说明书、获得合理的工作量认可。实际竣工行为是事实基线，已复核的 NESMA 结论是计量基线。两份 TeX 待完善稿供用户补充后提交客户确认和验收。

## Workflow

1. 读取并完成 [启动访谈.md](references/启动访谈.md)。在用户于后续一轮明确确认完整摘要前停止，不访问业务证据、不创建文件。
2. 确认后读取并完成 [证据审查与阻断.md](references/证据审查与阻断.md)。审查完成前不得读取成稿指令、填充模板或生成交付件。
3. 任一实质冲突均阻断成稿。完成本轮只读审查，一次列明全部已发现冲突、证据、影响和所需修正，然后停止。取得修正后的输入再按审查指令重新确认基线与审查。
4. 只有证据审查无阻断项时，读取并执行 [成稿与校验.md](references/成稿与校验.md)。

默认交付需求说明书、功能清单两份独立且完整的 `.tex` 源文件。仅在用户明确要求时编译 PDF 或转换 Excel。成稿组织和结构示例见成稿阶段引用的参考文件；工具约定保持简短。

写作阶段不承担 NESMA 识别、计数或方法复核，只接受已复核的详细 FPA 结论。缺少正式结论或发现计量不一致时停止成稿，列明需要补充或修正的输入。
